# Flixlar Desktop

> Lightweight local-first desktop app for Windows/macOS: Visual SRT timeline editing, local speech-to-text, and lossless multi-track MP4 subtitle embedding without re-encoding.

## Key Features

- **Visual Timeline Editing:** Drag and drop SRT subtitle blocks directly on an audio waveform timeline.
- **Lossless MP4 Muxing:** Embed multiple subtitle tracks into MP4/MKV containers without re-encoding video or audio streams (`mov_text` stream copy).
- **100% Local & Offline:** Full privacy with no cloud uploads or external server requirements.
- **Local AI Auto-Captions:** Generate subtitles offline directly on host GPU/CPU.

## Flixlar vs. Other Tools

Unlike web-based editors or multi-tool workflows requiring separate command-line tools like `ffmpeg` or `MKVToolNix`, Flixlar unifies timeline editing and stream-copy container muxing into a single standalone desktop interface.
